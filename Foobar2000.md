foobar2000 is a freeware audio player for Windows, macOS, iOS and Android.

* [Website](https://www.foobar2000.org/)

### Setup

On Windows, use the [foo_scrobble_librefm](https://github.com/httpsterio/foo_scrobble_librefm) component.

* Install the `.fb2k-component` from [Releases](https://github.com/httpsterio/foo_scrobble_librefm/releases)
* Open Preferences > Tools > Libre.fm Scrobbling and click Request authorization
* Allow access on Libre.fm, then click Complete authorization in foobar2000
